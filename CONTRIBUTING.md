# Contributing to FounderRadar Pro

Thank you for your interest in contributing! Here are guidelines to get started.

## Development Workflow
1. Fork the repository and create your feature branch:
   `git checkout -b feat/your-feature`
2. Install dependencies:
   `npm install`
3. Run the development server:
   `npm run dev`
4. Verify your changes pass production builds:
   `npm run build`
5. Open a Pull Request with a clear description of your changes.

## Code Standards
- Keep components modular and functional.
- Adhere to the minimalist dark theme color tokens.
- Ensure all external links include `rel="noreferrer"` and open in new tabs.
